# GEM1248 · 合成小紫棋

[点击直接玩](https://davidchen99.github.io/gem1248/)

邓紫棋 I AM GLORIA 巡演 Q 版主题的四乘四数字合成小游戏。手机上下左右滑动棋盘，电脑使用方向键或 WASD。

相同数字合并，从 1、2 开始向 2048 挑战。每次有效移动随机出现一个 1 或 2；无效移动不会新增方块。得分为所有新合成数字之和。

从 128 开始，每局第一次合成 128、256、512、1024、2048 及更高数字时，会打开对应的鼓励页面，展示 Q 版造型和该阶段的鼓励文案。低于 128 的数字不弹出鼓励页面。点击「继续闪耀」返回原棋盘；弹窗期间游戏暂停。

每种数字每局只鼓励一次，撤销、刷新或再次合成相同数字不会重复打断。开始新一局会重置。同一步首次合成多个新数字时，合并为一张庆祝页面；首次合成 2048 的鼓励与获胜庆祝也合并展示。

支持撤销一步、造型图鉴、最高分、自动续玩、可关闭的合成音效和 2048 后继续挑战。数据保存在当前浏览器。

## 独立公开网站

公开网址为 `https://davidchen99.github.io/gem1248/`，由 GitHub Pages 托管。访客无需 ChatGPT、GitHub 或游戏账号。全部逻辑、样式和图片来自同一网站，不请求 ChatGPT API、外部 CDN 或远程字体；电脑无需开机。

`index.html`、`style.css`、`engine.js`、`app.js` 和 `assets/` 构成完整静态游戏，`.nojekyll` 禁用 Jekyll 处理。直接从 main 分支根目录发布。

## 高清素材与来源

8 套巡演角色是依据舞台照片创作的 Q 版同人插画。每张素材均为 512×512 透明 WebP，数字与界面使用浏览器原生显示，适配手机高像素密度。256 至 2048 是白金、黑金与婚纱造型的荣耀光效变体。

这是非官方粉丝同人小游戏。

## 本地运行

运行 `python -m http.server 8767 --bind 127.0.0.1`，在浏览器打开 `http://127.0.0.1:8767/`。

更新源码后提交并推送到 main，GitHub Pages 自动更新网页。生产访问验证和分阶段鼓励页面测试保存在本机上层 `gem1248/qa/` 与 `gem1248/tests/`，不需要发布测试工具。
